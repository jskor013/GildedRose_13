# Gilded Rose Golden Master 회귀 테스트 구현 작업 보고서

## 1. 작업 목적

본 보고서는 C++17, Google Test, CMake 기반 Gilded Rose 프로젝트에 TextTestFixture 출력 기반 Golden Master 회귀 테스트를 설계하고 구현한 내용을 기록한다.

이번 작업의 목적은 기존 레거시 동작을 승인된 텍스트 출력으로 고정하여, 향후 리팩터링이나 기능 변경 시 의도하지 않은 동작 변화가 즉시 감지되도록 하는 것이다.

## 2. 작업 범위

- TextTestFixture 스타일의 30일 시뮬레이션 출력 생성
- 승인된 expected 출력 파일 생성 및 보관 전략 적용
- Google Test에서 Golden Master 파일 비교 테스트 구현
- CMake 및 CTest 통합
- GitHub Actions 기반 CI 자동 실행 구성
- 실행 및 승인 파일 갱신 방법 문서화

## 4. expected 출력 파일 생성 및 보관 전략

승인된 Golden Master 출력은 소스 트리의 `cpp/test/approval/gilded_rose_30_days.approved.txt`에 보관한다.

이 파일은 테스트 입력 인벤토리와 30일간의 `updateQuality()` 결과를 텍스트로 직렬화한 기준 출력이다. 소스 트리에 함께 커밋하여 모든 개발자와 CI가 동일한 기준으로 회귀 테스트를 실행하도록 했다.

실제 실행 결과가 기준 출력과 다를 경우, 테스트는 빌드 디렉터리 아래에 received 파일을 남긴다.

- approved: `cpp/test/approval/gilded_rose_30_days.approved.txt`
- received: `cpp/build/approval/gilded_rose_30_days.received.txt`

승인 파일은 의도적인 동작 변경이 있을 때만 다음 환경 변수를 사용해 갱신한다.

```powershell
$env:GILDED_ROSE_APPROVAL_UPDATE = "1"
ctest --test-dir "cpp/build" -R "TextTestFixture" --output-on-failure
Remove-Item Env:\GILDED_ROSE_APPROVAL_UPDATE
```

## 5. Google Test 구현 내용

`cpp/test/GildedRoseApprovalTest.cpp`에 `TextTestFixture`를 추가했다.

테스트는 다음 순서로 동작한다.

1. 대표 인벤토리를 생성한다.
2. day 0부터 day 30까지 모든 아이템 상태를 TextTestFixture 형식으로 출력한다.
3. 생성된 실제 출력과 approved 파일을 비교한다.
4. 차이가 있으면 received 파일을 생성하고 테스트를 실패시킨다.
5. approved 파일이 없으면 received 파일을 생성하고 승인 파일 생성 방법을 안내한다.

Windows와 Linux에서 줄바꿈 차이로 인한 불필요한 실패를 피하기 위해 approved 파일 읽기 시 CRLF/LF를 정규화한다.

## 6. CMake 및 CTest 통합

`cpp/CMakeLists.txt`에 `gilded_rose_approval_test` 실행 파일 타깃을 추가했다.

승인 파일 경로와 received 파일 경로는 CMake compile definition으로 테스트 바이너리에 주입한다.

- `GILDED_ROSE_APPROVAL_DIR`
- `GILDED_ROSE_RECEIVED_DIR`

`gtest_discover_tests(gilded_rose_approval_test)`를 사용해 CTest가 Golden Master 테스트를 자동 발견하도록 구성했다.

## 7. CI 자동 실행 구성

`.github/workflows/cpp.yml`을 추가해 GitHub Actions에서 다음 단계를 자동 실행하도록 했다.

```yaml
cmake -S cpp -B cpp/build -DCMAKE_BUILD_TYPE=Release
cmake --build cpp/build --config Release
ctest --test-dir cpp/build --build-config Release --output-on-failure
```

이를 통해 push와 pull request 시 단위 테스트와 Golden Master 테스트가 함께 실행된다.

## 8. 검증 결과

다음 명령으로 빌드와 전체 테스트를 확인했다.

```powershell
cmake -S "cpp" -B "cpp/build"
cmake --build "cpp/build"
ctest --test-dir "cpp/build" --output-on-failure
```

검증 결과는 다음과 같다.

```text
100% tests passed, 0 tests failed out of 26
```
